# TomvisHIMPro 3.0 — Migration & Implementation Roadmap

## Migration Strategy
TomvisHIMPro 3.0 builds directly on top of the existing v2.1 codebase without destroying current database schemas, existing patient search, MedRec, allergy, or security lab features.

## Delivery Stages & Phases
- **Stage A (Platform Foundation):** Core 3.0 extensions (Cache, Job Queue, Feature Flags, CLI enhancement, Central DB verification).
- **Stage B (Developer Productivity):** Web Developer Studio (`/developer`), Module Generator, CRUD Builder, Form Builder, API Generator, Report Builder.
- **Stage C (Quality & Security):** Enhanced 12-Scenario Sandbox, Web Test Runner, Security Lab ASVS Workflow.
- **Stage D (Operations & Registry):** Deployment Studio, Monitoring Center, Module Registry, FHIR Foundation, Thai Documentation.
- **Stage E (Validation & Benchmarking):** **PDH Pharmacy Queue Reference Module** & Real Development Time-Saving Benchmark Tool.
